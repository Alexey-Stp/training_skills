# Reviewing a swim

Read from `coach-review-session` before writing a swim's Splits, Execution or name. The examples use invented numbers.

## Splits and Execution

A swim is its sets, so the Splits section lays out all of them, in order, from the laps: what the set was, pace per 100 m (a range across the reps), rest, heart rate, and SWOLF or strokes where the laps hold them. Name drills and equipment on the set's line. Execution then judges against the planned session's `Sets:` line, set by set (without laps, say that the sets could not be checked), and gives only the size of each miss (reps short, seconds off the range, rest over the plan, beats over the cap). A set the plan did not have is named in Notes and counts toward the verdict and the caps.

```
⏱ Sets (pace per 100 m · rest · HR)
WU 300 · 1'58 · HR 118
4x50 drill · 2'05-2'12 · r20" · HR 110-121
5x200 · 1'52-1'55 · r30-40" · HR 131-136 · SWOLF 38-39
8x50 fins · 1'45-1'48 · r15" · HR 138-146
CD 100 · 2'02 · HR 115
```

## Name

`Swim - ` and the sets as swum, in order, joined by `/`. Each set is its distance or reps, a word for a drill or equipment, and for a main set (not the warm-up, drills or cool-down) `@` with the pace per 100 m across the reps. For example `Swim - 300/4x50 drill/5x200@1'52-1'55/8x50 fins@1'45-1'48/100`. Without laps: the planned session's title in title case, or the sport and its character for an unplanned swim.
